# Generated PROVN app

Run `npm ci`, then `npm run dev`. Set `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` and `SITE_URL` in `.env.local` to connect a dedicated Supabase project. Never use PROVN's production database or service key. Apply `supabase/migrations/001_product.sql` to that dedicated project. Enable email magic links and allow `SITE_URL/auth/confirm` in its Auth redirect allowlist. Its email template must link to `.ConfirmationURL` or `.RedirectTo` with `&token_hash={{ .TokenHash }}&type=email` appended.

The generated template implements pages and owner-scoped create/read/update/delete. The product UI under `app/` and `components/` is written by PROVN's Claude code agent; the data route, auth, migration and config are trusted template code. External integrations, deployment, security certification and bespoke workflow logic are not included. Review product.json, requirements and acceptance criteria before release. The build report distinguishes compilation checks from product acceptance.
